GURT, the GURT Universal Repository Thingy

Every distro's apps, on every distro.

GURT Universal Repository Thingy. The AUR on Mint, apt on SUSE, zypper on Red Star OS… plus Main GURT, a community repo of 2,500+ apps. Free and open source (MIT).

GURT for Linux

the GURT Setup Wizard as your distro's own package
your system

Open it like any package. It installs GURT and the app, then the setup wizard picks your sources, your look and your first apps. Updates come with your normal system updates.

🪟

GURT for Windows

Windows 10 / 11, through WSL
your system

Sets up WSL if you don't have it, installs GURT inside it, and puts a gurt command and the GURT app in your Start menu. Linux apps you install show up there too.

🛡️ Windows might say "Windows protected your PC". GURT isn't malware, here's why that shows up:

GURTSetupWizard.exe isn't code-signed yet (that costs money), so Windows SmartScreen doesn't recognize it. It warns about every new unsigned app, not just this one.

  1. click More info
  2. click Run anyway

⚠️ Only do this with the file from GURT's GitHub releases. If you got a "GURTSetupWizard.exe" anywhere else, delete it. And if Windows Defender says it found a virus (not just "unrecognized app"), stop and don't run it. You can check your file against SHA256SUMS on the release page: Get-FileHash GURTSetupWizard.exe in PowerShell.
